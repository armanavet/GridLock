# Gridlock, standalone

Generated by `tools/build_gridlock_standalone.py`. Edit the site, not this folder.

Upload everything in this folder to any static host. `index.html` is the page to
open. No backend or build step; the puzzle comes from the date.

## Messages

The game posts the same messages as on the site, to the page around it
(`index.html`). If `index.html` is itself embedded in another site, each one is
passed up to that site unchanged. Every message also carries
`source: "lat-games"`, `v: 1` and `ts`.

| event | fields | when |
|---|---|---|
| `game_start` | `puzzleId`, `engine: "gridlock"` | the player has loaded |
| `assist_used` | `action: "guess"`, `n` | a guess is submitted |
| `game_complete` | `puzzleId`, `seconds`, `guesses`, `solved` | solved, or out of guesses |
| `share_clicked` | `target`: `copy`, `facebook`, `x`, `whatsapp` | a share is used |
| `navigate` | `gameId`, `view: "archive"` | More puzzles |
| `navigate` | `gameId`, `view: "puzzle"`, `puzzleId` | an archive row is opened |
